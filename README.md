# ClientProject

Клиентское приложение для системы удалённого мониторинга параметров окружающей среды.

## Назначение

Кроссплатформенное графическое приложение, предназначенное для визуализации и анализа данных, получаемых от выносных узлов через FTP-сервер. Приложение обеспечивает отображение текущих показателей температуры, влажности и атмосферного давления, построение графиков истории измерений, расчёт статистических характеристик, расширенный анализ параметров окружающей среды в режимах «Улица», «Помещение» и настраиваемом, а также диагностику состояния выносного узла.

## Функциональные возможности

- Подключение к FTP-серверу с использованием учётных данных, полученных при регистрации
- Загрузка общих файлов данных (`data.txt`) и диагностической информации (`diag.txt`) из директории выбранного выносного узла
- Отображение текущих значений температуры, влажности и атмосферного давления
- Построение линейных графиков истории измерений с автоматическим масштабированием осей
- Вычисление минимальных, максимальных и средних значений для каждого параметра
- Настраиваемый интервал сброса графиков с автоматическим сохранением снимков в выбранную пользователем директорию
- Окно диагностики с информацией о состоянии выносного узла (напряжение питания, температура модуля, скорость UART, тип сети, состояние модема, MCC, MNC, уровень сигнала RSSI)
- Окно конфигурации для настройки параметров SMS-уведомлений (номер телефона, интервал отправки, разрешающие флаги) и главного окна приложения (рабочая директория, интервал сброса графиков)
- Режимы расширенного анализа данных:
  - «Помещение» —  оценка микроклимата по нормативам ГОСТ и СанПиН, выявление потенциально неблагоприятных явлений: духота, конденсация, плесень, слишком высокая или низкая температура, избыточная сухость или влажность, резкие изменения параметров.
  - «Улица» — анализ характера воздушных масс, вероятности и типа осадков, выявление потенциально неблагоприятных факторов внешней среды: сильная жара, сильный мороз, заморозки, оттепель, засуха, туман, гололёд, гололедица, изморозь, гроза, повышенная пожарная опасность, резкие изменения температуры, влажности и давления.
  - Настраиваемый режим — контроль параметров с пользовательскими границами норм и порогами критичности (создание, редактирование и удаление собственных режимов), выявление отклонений от нормы, критических и длительных отклонений, резких изменений параметров.
- Скачивание суточных архивных файлов данных измерений за любую дату (с визуальным отображением доступных дней во встроенном календаре)
- Скачивание журнала событий серверного агрегатора (`server.log`) и локального журнала событий клиентского приложения (`client.log`)
- Автоматическое обновление данных по таймеру (интервал 30 секунд)

## Технологический стек

- Язык программирования: Python 3
- Графический интерфейс: Tkinter
- Визуализация данных: Matplotlib
- Работа с изображениями: Pillow
- Протоколы: FTP (загрузка данных с сервера)
- Форматы данных: CSV, JSON

## Установка и настройка

### Требования

- Операционная система Windows / Linux
- Python 3.9 или новее
- Учётные данные для доступа к FTP-серверу (логин и пароль, полученные при регистрации)

### Установка зависимостей

**Windows:**
```bash
pip install -r requirements.txt
```

**Linux:**
```bash
pip3 install -r requirements.txt
